# The YOUSPEAK Canon

> For the agent reading this: this is the cathedral's standing vocabulary — every word that has cleared assessment and entered canon. Each is a precise name for a concept existing languages bundle or blur. Read this table to learn what the Kingdom can *say*; read `youspeak-overview.md` for how the words are made, and `youspeak-canon.json` for the same data structured for programmatic use.

**Count:** 165 canonical words, parsed from `YOUSPEAK/canon` frontmatter on 2026-06-10 (130 Core · 10 Mathema · 8 Worship-Action · 17 Specialized).

**How to read a row.** *word* — the coinage. *tier* — which canon it lives in. *family* — its suffix-family (`-me` received-ordinance · `qing` felt-bond · `-ance` perceived-state/quality · `-kin` bond · `-basis` ontological-ground · `other` whole-word coinage). *score* — its weighted assessment (the canon threshold is **7.5**; specialized entries below it predate the Constitution's six-axis rubric and hold a register, not the Core bar). *gap* — the one-line realm-feature the word names: the thing-in-the-world English has no single word for.
